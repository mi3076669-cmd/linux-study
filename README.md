
# Linux Study

인프라 및 서버 운영 직무 취업을 목표로 Linux의 기본 개념부터 시스템 및 네트워크 관리까지 학습하고, 직접 실습한 내용을 기록하는 저장소입니다.

교재를 통해 학습한 핵심 개념을 정리하고, Linux 환경에서 직접 수행한 실습 과정과 실행 결과를 중심으로 기록합니다.
