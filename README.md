# Linux Study

인프라 및 서버 운영 직무 취업을 목표로 Linux의 기본 개념부터 시스템 및 네트워크 관리까지 학습하고, 직접 실습한 내용을 기록하는 저장소입니다.

단순한 이론 정리보다는 Linux 환경에서 직접 명령어를 실행하고, 실행 결과와 문제 해결 과정을 기록하는 것을 목표로 합니다.

---

## 1. 학습 환경

- 학습 교재: 쉽게 배우는 리눅스
- Host OS: Windows
- Virtual Machine: VMware / VirtualBox
- Guest OS: Ubuntu Linux
- 학습 도구: Linux Terminal, GitHub, Notion

※ 실습 환경은 실제 사용한 운영체제와 가상머신에 맞게 수정합니다.

---

## 2. 학습 목표

- Linux 운영체제의 기본 개념과 구조 이해
- Linux 기본 명령어 및 파일 시스템 활용
- 사용자, 파일 접근 권한 및 프로세스 관리
- 셸 스크립트를 활용한 작업 자동화
- Linux 시스템 및 네트워크 관리 기초 습득
- 실습 내용을 GitHub에 기록하고 서버 운영 프로젝트로 확장
