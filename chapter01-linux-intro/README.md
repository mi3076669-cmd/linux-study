
# Chapter 01. Linux 개요 및 실습환경 구축

## 1. 학습 개요

Linux의 기본 구조와 운영체제의 역할을 학습하고, VMware를 이용하여 Ubuntu 실습환경을 구축하였다.

## 2. 핵심 개념

### 2.1 커널과 셸의 역할

- **커널(Kernel)**: 시스템의 자원을 관리하는 운영체제의 핵심
- **셸(Shell)**: 사용자의 명령을 해석하고 프로그램 실행을 지원하는 인터페이스

### 2.2 사용자 모드와 커널 모드

일반 응용 프로그램은 제한된 권한인 사용자 모드에서 실행되며, 운영체제의 보호된 자원에 접근할 때는 시스템 호출(System Call)을 이용한다.

커널은 커널 모드에서 하드웨어 제어 및 시스템 자원 관리 등 특권이 필요한 작업을 수행한다.

## 3. 실습환경

| 항목 | 구성 |
| --- | --- |
| 가상화 소프트웨어 | VMware Workstation Pro |
| 운영체제 | Ubuntu 24.04 Desktop |
| 가상 디스크 | 20GB |
| 설치 상태 | 설치 완료 및 정상 실행 확인 |

## 4. 직접 수행한 실습

- VMware Workstation Pro를 이용한 Ubuntu 가상머신 구성
- 가상 디스크 20GB 설정
- Ubuntu 24.04 Desktop 설치
- Ubuntu 정상 실행 확인

## 5. 실습 결과 및 배운 점

가상머신을 활용하여 기존 컴퓨터에서 독립적인 Linux 환경을 구성할 수 있다는 것을 확인하였다.

VMware에 Ubuntu 24.04 Desktop을 설치하고 정상적으로 실행되는 것을 확인하였으며, 이후 Linux 명령어 및 시스템 관리 실습을 진행할 수 있는 환경을 마련하였다.
